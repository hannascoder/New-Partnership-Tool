# Configuration: all allowed values

Everything the Partner Finder may use as a value lives here, not in the code.
You can open and edit these files directly on GitHub (pencil icon). After a
change, the check `Check config` runs by itself and tells you if something is wrong.

| File | What it contains | Edit by hand? |
|---|---|---|
| `categories.yaml` | Scope, material, organisation types, channels, social platforms, ownership, topics (5 Ps + beats), UN profile, size, checkboxes, sorting, classification methods | Yes: labels any time; ids never change once used |
| `countries.csv` | 193 UN member states + 2 observer states (State of Palestine, Holy See), with UN M49 region, subregion and intermediate region, plus everyday names for the search (`aliases`) | Only `aliases`. The rest is generated, see below |
| `languages.csv` | 7,027 living languages (ISO 639-3). The 9 language buttons have a number in `button` (1-9 = display order) | Only `name` and `button`. The rest is generated |
| `rules.yaml` | Rules that assign categories ("member of X → topic Y"). Empty until step 4 | Yes |
| `../overrides.csv` | Hand corrections for single outlets. They always win | Yes |

## Regions
Regions follow UN M49. The website shows **region** (Africa, Americas, Asia, Europe, Oceania)
and then the finest level available: the **intermediate region** if there is one
(e.g. Middle Africa, Caribbean, South America), otherwise the **subregion**
(e.g. Western Asia, Northern Europe).

Territories that are not UN member or observer states (e.g. Hong Kong, Taiwan,
Kosovo, Puerto Rico) are not in `countries.csv`; outlets based there are left out.

## Where countries.csv and languages.csv come from
They are generated by `pipeline/setup/build_reference_lists.py` from the files in
`raw/reference/`:

| File | Source |
|---|---|
| `un-membership.csv` | The 195 countries of the Audience Intelligence Atlas (193 members + 2 observers). Matches the UN list at un.org/en/about-us/member-states |
| `iso3166-m49_lukes.csv` | ISO 3166 codes with UN M49 regions, from github.com/lukes/ISO-3166-Countries-with-Regional-Codes |
| `iso639-3.json` | ISO 639-3 codes (SIL International), via the npm package `iso-639-3` 3.0.1 (MIT) |

Country names follow the UN's word order (e.g. "Republic of Korea", "Iran (Islamic Republic of)").
